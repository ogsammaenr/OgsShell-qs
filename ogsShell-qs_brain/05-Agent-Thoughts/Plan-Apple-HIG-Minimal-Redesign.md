# Proposal: Apple HIG Minimalist Dynamic Island Redesign (Anti-AI-Slop)

> [!IDEA]
> Complete visual overhaul of the Dynamic Island and Clock App Suite to achieve true Apple HIG minimalism: stripping emojis, adopting pitch black OLED surfaces, implementing sliding segmented controls, iOS-style circular action dials, and tabular typography.

## 1. Identified AI-Slop Flaws
1. **Emoji Clutter:** Emojis like `🍅`, `☕`, `🌴`, `🇹🇷`, `🎯`, `✓`, `⚙️` used in primary controls.
2. **Nested Card Grids:** Boxing every detail inside gray bordered rectangles.
3. **Disjointed Tabs:** Separate pill buttons with harsh active borders.
4. **Heavy Stepper Rectangles:** Clunky box steppers.

## 2. Planned Minimalist Solutions
1. **Unified Sliding Segmented Control:** Single pill track with spring-animated thumb capsule for tabs.
2. **Apple Watch / iOS Circular Action Buttons:** Round 36-40px buttons with subtle translucent tints.
3. **Clean Tabular Figures:** Precise digital typography without digit wobbling.
4. **Hairline Keyline Strokes:** Translucent 1px borders (`rgba(255, 255, 255, 0.08)`).
5. **No Emojis in Core UI:** Replaced with clean text and minimalist semantic symbols.
